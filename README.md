# Pricenerds3D

Snerds/Sridds & I created our own custom light-weight animation tools for more performance critical or experimental environments like VR! Targeted toward programmer-heavy teams like ourselves who want to understand and tweak the pipeline. 

![ee07c3ae-9694-4a2e-9c41-caa5f30004ac](https://github.com/user-attachments/assets/431e9177-e8ae-42ae-88a3-75af7bb47283)


### Features
* HTR Support with custom importer that uses ScriptableObjects
* Blending
* FK & IK Solver
* 3-chain pole vector & look-at IK
